# Zutto Petto

Zutto Petto は、ペットのDNA・テロメア検査結果をもとに健康状態をスコア化し、飼い主の日々の生活改善につなげる予防型ペット保険・健康管理サービスのMVPデモです。

本アプリは事業説明用のモックです。本番の医療診断、遺伝子解析、保険審査、外部API連携、DB保存は行いません。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 技術構成

- Next.js App Router
- TypeScript
- Tailwind CSS
- モックデータ: `src/lib/mockData.ts`
- 外部APIなし
- DBなし

## 主な画面

- `/`: 飼い主向けホーム
- `/health-check`: **うちの子健康寿命チェック（公式LINE向け・ログイン不要）**
- `/health-check/form`: 診断フォーム（11問・ステップ形式）
- `/health-check/result`: 診断結果（localStorage に保存）
- `/pets`: ペット一覧
- `/pets/new`: うちの子プロフィール登録
- `/pets/[id]`: ペット詳細
- `/pets/[id]/telomere`: テロメア検査結果
- `/pets/[id]/daily-log`: 毎日の健康記録
- `/advice`: AI健康アドバイス
- `/insurance-dashboard`: 保険会社向け管理画面

## 健康寿命チェック（公式LINE向け MVP）

公式LINEからの流入を前提とした、**ログイン不要**の簡易診断フローです。

- **Googleログインは使用しません**（LINE内ブラウザ・Instagram内ブラウザでの OAuth エラーを回避）
- 入力 → 結果表示までは **localStorage** のみで完結
- 将来 Firebase / Supabase へ移行しやすいよう、データ構造とストレージ層を分離（`src/lib/healthCheckStorage.ts`）
- LINE CTA の URL は `.env` の `NEXT_PUBLIC_LINE_OFFICIAL_URL` で差し替え可能

**LINE公式アカウントに設定するURL例:**

```
https://your-domain.com/health-check
```

## 事業説明

通常のペット保険は、病気やケガが起きた後の保険金支払いが中心です。Zutto Petto は、病気になる前の健康状態を見える化し、食事・運動・生活習慣の改善を促すことで、ペットの健康寿命を伸ばし、保険会社の将来的な損害率改善にもつなげることを目指します。

飼い主向けには「うちの子を長く元気に」という安心感のある体験を提供し、今日の状態、今日やること、相談目安、やさしい健康アドバイスを中心に表示します。

保険会社向けには、契約ポートフォリオを分析するBtoBダッシュボードとして、KPI、リスク分布、犬/猫別・年齢帯別の平均スコア、通院回数推移、介入優先リスト、損害率改善シミュレーションを表示します。

## 2つの利用者体験

### 飼い主向け

- 今日の状態をスコア、健康年齢、記録継続日数で確認
- `/pets/new` から、名前、犬/猫、品種、年齢、性別、体重、飼い主名を入力してペットを追加
- 追加したペットは `localStorage` に保存され、同じブラウザでは一覧・詳細・テロメア結果に表示
- 今日やることを行動カードで確認
- 気をつけるサインを病気の断定ではなく相談目安として確認
- 毎日の健康記録をボタン中心のフォームで入力
- ペットごとに、なぜそのアドバイスなのかを含めて確認
- テロメア結果では、実年齢と健康年齢の差、同年齢平均との差、差を埋めるための予防ケアを確認

### 保険会社向け

- 契約ペット全体のリスク状況をKPIで確認
- MVPでは飼い主が追加したペットもデモ集計に含めて表示
- リスクレベル、種別、年齢帯ごとの傾向を確認
- 介入優先度、請求リスク、期待削減額を一覧で確認
- 損害率改善シナリオと前提条件を説明可能な形で確認

## 注意事項

画面内のテロメアスコア、健康年齢、AIアドバイス、損害率改善シミュレーションはすべてモックデータです。本サービスは診断ではなく、健康管理の参考情報です。気になる体調変化がある場合は、必ず動物病院に相談してください。
